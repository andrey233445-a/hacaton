# Проект «Школьный штаб»

Асинхронный MAX-бот с личными кабинетами ученика, учителя, родителя и психолога. Данные хранятся в PostgreSQL; регистрация активна сразу, а управление пользователями доступно в веб-панели администрирования.

## Стек технологий

- **Python 3.12+** -- рекомендуемая версия для разработки и запуска.
- **maxapi** -- асинхронный бот MAX, работающий через long polling.
- **SQLAlchemy 2.x** и **asyncpg** -- асинхронная работа с базой данных PostgreSQL.
- **PostgreSQL 15** -- реляционная база данных.
- **Alembic** -- управление миграциями схемы базы данных.
- **FastAPI**, **Uvicorn** и **Jinja2** -- веб-панель управления и мини-приложение.
- **python-dotenv** -- конфигурация через переменные окружения.
- **cryptography (Fernet)** -- шифрование паролей школьных классов.
- **Docker Compose** -- запуск сервисов в изолированных контейнерах.

Зависимости проекта зафиксированы в файле `requirements.txt`, конфигурация контейнеров описана в `Dockerfile` и `docker-compose.yml`.

## Инструкция по запуску

Проект можно запустить двумя способами: через командную строку (локально) или в Docker-контейнерах.

---

### Вариант 1. Запуск через командную строку (CLI / venv)

Для запуска необходимы установленный Python 3.12+ и работающий сервер PostgreSQL.

#### 1. Клонирование репозитория и переход в папку:
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ИМЯ_ПАПКИ_РЕПОЗИТОРИЯ>
```

#### 2. Создание и активация виртуального окружения:
- На Linux и macOS:
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  ```
- На Windows (PowerShell):
  ```powershell
  python -m venv .venv
  .\.venv\Scripts\Activate.ps1
  ```

#### 3. Установка всех библиотек и зависимостей:
Все версии библиотек зафиксированы в `requirements.txt`:
```bash
pip install -r requirements.txt
```

#### 4. Настройка файла конфигурации (.env):
Скопируйте шаблон переменных окружения:
```bash
cp .env.example .env
```
Укажите в `.env` параметры подключения к базе данных (`DATABASE_URL`), токен бота MAX (`BOT_TOKEN`) и пароль администратора (`ADMIN_PASSWORD`).

#### 5. Применение миграций базы данных:
```bash
alembic upgrade head
```

#### 6. Запуск MAX-бота:
```bash
python -m app.main
```
Бот запустится в режиме long polling и будет готов принимать сообщения в MAX.

#### 7. Запуск веб-панели управления и мини-приложения:
В отдельном окне терминала запустите Uvicorn:
```bash
uvicorn app.admin_web.main:app --host 0.0.0.0 --port 8000
```
- Панель управления аккаунтами: http://localhost:8000/admin/accounts (логин `admin`, пароль из `.env`)
- Мини веб-приложение: http://localhost:8000/mini

---

### Вариант 2. Запуск через Docker Compose

Все сервисы (PostgreSQL 15, автоприменение миграций Alembic, бот и веб-панель) настроены в `docker-compose.yml`.

#### 1. Подготовка конфигурации:
```bash
cp .env.example .env
```
В файле `.env` укажите токен бота `BOT_TOKEN` и пароли к базе данных.

#### 2. Сборка и запуск контейнеров:
```bash
docker compose up --build -d
```
Docker автоматически:
1. Запустит базу данных PostgreSQL.
2. Дождется готовности базы данных.
3. Применит все миграции через одноразовый контейнер `alembic upgrade head`.
4. Запустит бота и веб-сервис на порту 8000.

#### 3. Управление контейнерами:
- Проверка статуса сервисов:
  ```bash
  docker compose ps
  ```
- Просмотр логов бота:
  ```bash
  docker compose logs -f bot
  ```
- Перезапуск бота:
  ```bash
  docker compose restart bot
  ```
- Остановка контейнеров:
  ```bash
  docker compose down
  ```

## Реализованный функционал

- **Кабинет ученика:** расписание уроков (день, завтра, неделя), отслеживание домашних заданий со статусом сдачи, трекер дедлайнов и контрольных работ, система мотивации с баллами и наградами, модуль «Антистресс» с дневником настроения, карточками практик и возможностью отправить сигнал школьному психологу.
- **Кабинет учителя:** создание и управление классами (с генерацией логина и пароля), ведение расписания уроков, выдача домашних заданий с назначением баллов за сдачу, публикация объявлений для класса, отчетность по сдаче заданий.
- **Кабинет родителя:** привязка к профилю ученика с подтверждением со стороны ребенка, сводка учебных событий, автоматические уведомления о предстоящих контрольных работах.
- **Кабинет психолога:** просмотр поступающих сигналов учеников, фиксация статуса обращения («в работе», «завершено») и анонимная связь для поддержки.
- **Административная веб-панель:** поиск, фильтрация пользователей по роли и статусу, ручная смена роли и удаление учетных записей.

## О проекте

Проект разработан для хакатона «Идея фикс». Основная цель -- создать удобную и понятную цифровую среду для школьного сообщества прямо в мессенджере MAX.

### Тестирование и надежность
Качество кода подтверждено набором автоматических тестов:
- **184 теста** покрывают сценарии FSM-диалогов бота, разграничение прав доступа (RBAC), REST API и взаимодействие с базой данных.
- Для запуска тестов выполните:
  ```bash
  pytest -v
  ```
